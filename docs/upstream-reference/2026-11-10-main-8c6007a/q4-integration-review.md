## Review发现并处理

1. 不照搬FF55默认提前拆链：上游“同一种应答重复”与实际总次数累计不一致；候选或分片不足以定性拒绝。本分支完全不增加失败分支或长度等待。测试在重复候选及故障日志回调后仍可正常协商，并比较未增加回调的engine状态/期限。
2. 不照搬“语音非零就证明命令生效”。增量报文不抹掉缺席模块，矛盾值不猜测，只有新HU重建观察器；记录是状态证据，不是因果证明。没有改硬键映射、助手路由或模块自动控制策略。
3. 不照搬STOP后零保护窗。媒体和TTS共用开停回调，真实媒体可能仍在流动；保留50ms保护、待处理队列检查和真实输入优先，避免因提示信号抢发静音。它不能恢复手机侧未发送的音乐，也不能保证完全消除提示音听感。
4. 原代码将352/48000秒每次截断为7ms，会让目标补帧节拍偏快；改成Double累计真实样本时长。每拍上限16帧使48K/352样本下具备覆盖100ms拍的容量，但仍按目标时间逐包到期发送，落后不无限追历史，不是每拍固定发16帧。
