# Q4 固定 Wi-Fi 记忆与预连接

## 明确策略

按用户2026-11-10补充指示，Q4热点凭据视为稳定：**一旦成功学习便固定使用，凭据错误也不自动替换，只有用户手动清除后才允许重新学习**。不做密码变化判断后的自动规避，不按失败次数/期限删除记忆。存在可读记忆时，新0x5703/0x4301携带不同SSID、密码或安全类型时，仅记一条不含凭据正文的差异摘要，实际入网、网络建议及后续端点统一使用固定值。相同目标的成功回调也不得覆盖已占用记录或刷新其内容。

连接仍受既有预算、退避、主动取消与离车保护限制；“一直使用同一记忆”不等于无限高速重试。预算耗尽后记录仍保留，下次启动继续使用它。不存在或不可解密/解析的记录视为无可用记忆，走正常连接，成功后重新学习；这与可读凭据连接失败严格区分。车机热点行显示“未记忆/已记忆固定使用/无法读取”状态，排障时可直接看到当前策略。

## 存储和学习

首次安装此功能没有记忆，需要一次正常连接。只在选定目标网络可用且CarPlay控制认证/会话成功后学习；验证目标蓝牙对端或已有该目标的记忆证明，不把另一车的凭据写入本目标。这是协议层成功，不是视觉解码确认。保存SSID、密码、安全类型、信道、首次验证时间；目标身份参与AES-GCM认证。

CarWifiMemory使用Android Keystore非导出AES-256密钥及应用私有偏好，Manifest原本已allowBackup=false。FixedWifiStore的检查与写入原子化，可正常读取的记录阻止覆盖；不可读记录在正常连接成功后允许替换。并发成功回调只允许首个可用记录落盘。不输出密码或异常负载，Keystore/文件访问放后台；BT回调首次选择时可能读取记忆，优先确保不会被新输入抢先绕过固定策略。

不保存/恢复Network对象、进程绑定、历史IP/发现结果、邀请、socket或配对控制密钥。端点仍在当前网络发现/解析，未因知道密码放宽目标网络身份校验。

## 预连接与生命周期

用户启动或原有靠近流程启动时，BT照常运行，同时尝试一次固定凭据预入网。复用WifiJoinGate和请求活性校验，不增加常驻扫描/轮询，不额外增加缓存重试轮数。绑定后对齐ctrl广播并开始发现；缓存路径要求本轮明确匹配目标的邀请才进入CarPlay建链，不凭旧密码直接占用配对窗口。邀请先到则暂存接续。排队时捕获所属票据，不能执行时换成新票据复活旧任务。

不同新凭据不取消缓存、不切换SSID、不重新绑定；已工作的控制/投屏也不因刷新受扰。目标切换、主动断开及旧任务晚到由所有权/工作票据隔离。两种CarLife先后顺序保留：不停止温源，晚到源继续等待及有界恢复。E7端口不开窗与BT误取消分别处理，本功能不能证明它们已消失。

## 手动清除

车机热点行新增“清除记忆”，仅断开后可执行，controller再次检查。清选定目标的持久化记录、内存凭据和端点、缓存票据及本应用对应网络建议。旧异步保存不能在终态/清除后写回。蓝牙配对、CarPlay身份以及其他目标的记忆保持；用户在系统WLAN手动保存的网络由系统设置管理。建议删除失败记录status/异常类别，应用记忆仍清除。

可读记录所对应的实际密码/SSID变化时操作固定为：断开 → 清除记忆 → 重新启动连接并学习；不会因连接失败自动替换。存储损坏无法还原旧建议参数时，应用记录仍可清除，系统建议清理可能受限，不删除其他目标或用户手动网络。
